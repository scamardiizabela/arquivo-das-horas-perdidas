# O Arquivo das Horas Perdidas

Jogo original de aventura point-and-click, mistério e fantasia, planejado para Android e iOS e desenvolvido em Godot 4.

## Estado
Pré-produção e protótipo da estação ferroviária de Vespera. O protótipo v0.2 foi criado como pacote local, mas ainda não foi validado no editor Godot. Este repositório será a fonte versionada do projeto.

## Capítulo 1: A Carta Impossível
Elara Voss chega à cidade de Vespera para investigar uma carta de uma pessoa apagada da memória de todos. A primeira cena jogável será a estação ferroviária, com inventário, relógio mecânico, pistas e navegação por toque.

## Direção artística
Fantasia histórica, arquitetura vitoriana, iluminação cinematográfica, neblina, mecanismos antigos e camadas 2.5D. Imagens de referência não são assets finais.

## Plano de integração
1. Importar o projeto Godot v0.2 e verificar erros de importação.
2. Implementar e testar a cena da estação e seus hotspots.
3. Substituir a arte temporária por assets originais em camadas.
4. Testar o inventário, os puzzles e o salvamento.
5. Validar no Android antes da preparação do build iOS.

## Branches
- `main`: base estável.
- `dev/estacao-vespera`: implementação e testes do primeiro cenário.

Nenhuma versão mobile está pronta para publicação.
