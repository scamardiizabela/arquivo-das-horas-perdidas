# Protótipo jogável 0.1 — Primeiro vagão

Abra a pasta `prototype/vagao` no Godot 4.2+ e execute F6/F5.

Este é um protótipo **funcional com arte provisória desenhada por código**. Não representa a direção artística final. Clique nas áreas identificadas, colete o comprovante, examine o formulário, abra o guarda-volumes com os três símbolos, recupere o estojo, encontre o grampo e a etiqueta M-17, abra a gaveta de manutenção e libere a porta.

A tecla Esc fecha o painel atual. O botão Diário mostra as pistas; Reiniciar limpa o progresso. A porta do corredor apresenta uma tela de encerramento desta versão.

Não há exportação web nem validação de execução no editor ainda. A branch `dev/prototipo-vagao` não altera o protótipo anterior da estação.
